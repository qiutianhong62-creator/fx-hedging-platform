# 第八阶段：远期策略自动概率比较设计

> 日期：2026-07-31
> 项目：`fx-hedging-platform`

## 1. 目标

把第七阶段已经验证过的多笔远期现金流计算接入现有市场预测与概率模型，使用户能够在同一套未来汇率概率分布下比较：

- 完全不套保；
- 用户当前输入的一套远期策略。

第一版回答以下问题：

- 两种方案预计对应多少人民币收入或成本；
- 两种方案常见和较极端的人民币金额范围；
- 两种方案达到用户目标金额的概率；
- 远期策略优于不套保的概率；
- 远期策略是否缩小了结果范围；
- 当前策略是否存在超额套保风险。

本阶段不同时比较多套策略。完整概率曲线、更多概率点和前端图表作为后续扩展。

## 2. 范围

### 2.1 本阶段支持

- 货币对仅支持 `USD/CNY`。
- 敞口类型支持美元应收、美元应付和持有美元。
- 用户输入一笔真实敞口和一笔或多笔同日到期的真实银行远期报价。
- 远期方向继续根据敞口类型自动决定。
- 使用现有机构预测生成到期汇率中心值。
- 使用现有历史数据计算年化波动率。
- 使用现有对数正态分布生成未来到期汇率概率分布。
- 在完全相同的市场分布下比较不套保和一套远期策略。
- 支持部分套保、全额套保和超额套保。
- 目标人民币金额保持可选。
- 返回现有市场数据来源、更新时间、缓存状态和局限性。

### 2.2 本阶段不支持

- 同时建立或比较多套远期策略。
- 完整概率曲线、密集概率点或直方图数据。
- 期权、掉期、期货或多产品组合。
- 不同到期日的远期组成项。
- 远期提前平仓、展期、保证金、授信和交易费用。
- 用户手工输入预测汇率或波动率。
- 多家机构共识预测。
- 银行远期报价是否“合理”或是否优于市场报价的判断。
- 直接给出“应该交易”或“不应该交易”的建议。

## 3. 接口

新增独立接口：

```text
POST /api/v1/analysis/forward-strategy/automatic-probability
```

保留现有确定性情景接口：

```text
POST /api/v1/analysis/forward-strategy/scenario
```

两个接口职责不同：

- `scenario` 使用用户填写的假设到期汇率，方便人工复算一条确定结果；
- `automatic-probability` 自动读取外部市场数据，计算一组概率结果。

这样既保留了简单、可验证的基础计算器，也避免把外部抓取逻辑混入纯现金流公式。

## 4. 用户输入

示例：

```json
{
  "currency_pair": "USD/CNY",
  "exposure_type": "usd_receivable",
  "notional_usd": 1000000,
  "maturity_date": "2026-11-15",
  "target_cny": 6680000,
  "forward_legs": [
    {
      "notional_usd": 300000,
      "forward_rate": 6.80
    },
    {
      "notional_usd": 200000,
      "forward_rate": 6.75
    }
  ]
}
```

与第七阶段相比，本接口不接收：

```text
assumed_maturity_spot
assumed_expected_maturity_spot
assumed_annualized_volatility_pct
```

这些数据由后端自动获得。其余输入校验沿用第七阶段：

- 敞口金额必须是有限且大于 0 的数；
- 至少包含一笔远期；
- 每笔远期金额和汇率必须是有限且大于 0 的数；
- 到期日必须在允许范围内；
- 目标金额可以省略，填写时必须是有限且大于 0 的数；
- 远期金额合计可以超过真实敞口，但必须返回风险提示。

## 5. 数据流和后端边界

```text
用户请求
  │
  ├─ 真实敞口
  ├─ 到期日
  ├─ 目标金额（可选）
  └─ 多笔远期报价
  │
  ▼
自动分析协调服务
  ├─ 调用现有到期汇率预测服务
  └─ 调用现有历史波动率服务
  │
  ▼
建立一套共同的到期汇率分布
  │
  ▼
纯概率比较计算器
  ├─ 不套保结果
  ├─ 远期策略结果
  ├─ 目标达标概率
  ├─ 策略优于不套保的概率
  └─ 结果范围变化
  │
  ▼
附加数据来源和局限性后返回
```

后端分为两层：

1. **自动分析协调层**负责访问预测和历史数据服务。
2. **纯概率计算层**只接收输入、预测中心值、波动率和估值日，不访问网络或缓存。

纯概率计算器必须满足：相同输入产生相同结果，并可以直接注入测试数据进行人工复算。

第七阶段的确定性远期计算规则应复用或抽取为共同函数，不能在新模块中复制另一套可能逐渐不一致的公式。

## 6. 共同市场分布

不套保与远期策略必须使用完全相同的：

- 估值日；
- 到期日；
- 机构预测中心值；
- 历史年化波动率；
- 对数正态分布。

分布建立逻辑复用现有 `build_lognormal_distribution`，不新增随机模拟或蒙特卡洛计算。

第一版继续使用：

- 25%—75%分位数作为常见的 50% 汇率范围；
- 5%—95%分位数作为较宽的 90% 汇率范围。

当前机构预测是单一机构试验，不是多机构共识预测。该局限必须继续出现在接口结果中。

## 7. 金额计算

定义：

```text
E  = 真实美元敞口
S  = 到期即期汇率
Ni = 第 i 笔远期美元金额
Fi = 第 i 笔远期汇率
H  = ΣNi，远期美元金额合计
C  = Σ(Ni × Fi)，远期锁定人民币金额合计
```

不套保人民币金额：

```text
no_hedge_amount(S) = E × S
```

远期策略人民币金额：

```text
strategy_amount(S)
= E × S + Σ[Ni × (Fi - S)]
= C + (E - H) × S
```

这与第七阶段逐笔远期差额公式完全一致，只是整理为适合概率计算的线性形式。

由于金额是汇率的线性函数，将预测的平均到期汇率代入公式，得到的也是人民币金额的期望值，不需要逐个随机生成汇率。

## 8. 预计结果和金额范围

两种方案分别返回：

- 预计到期汇率对应的人民币金额；
- 常见 50% 汇率范围下的人民币金额范围；
- 较宽 90% 汇率范围下的人民币金额范围。

不套保金额随 USD/CNY 汇率上升而上升。

远期策略的汇率敏感度为：

```text
E - H
```

因此：

- 部分套保时，策略金额仍随汇率上升，但变化更缓；
- 全额套保时，`E - H = 0`，策略金额固定；
- 超额套保时，`E - H < 0`，策略金额可能随汇率上升而下降。

为了正确处理超额套保，金额范围不能假设“较低汇率一定对应较低金额”。系统应分别计算区间两端金额，再使用较小值和较大值作为金额范围下限和上限。

## 9. 目标达标概率

如果用户填写目标金额，两种方案分别计算：

- `probability_met`：达到目标的概率；
- `probability_missed`：未达到目标的概率；
- `critical_spot`：目标对应的临界汇率；如果金额完全固定，则可以为空。

目标条件沿用现有业务含义：

```text
美元应收或持有美元 → 人民币收入大于等于目标即达标
美元应付           → 人民币成本小于等于目标即达标
```

对于一般线性金额函数：

```text
amount(S) = a + b × S
```

系统根据 `b` 的正负决定概率不等式方向：

- `b > 0`：金额随汇率上升；
- `b < 0`：金额随汇率下降；
- `b = 0`：金额固定，达标概率只能是 0% 或 100%。

这样可以正确处理部分、全额和超额套保，而不是只套用不套保的临界汇率公式。

如果用户没有填写目标金额，两种方案的目标概率均返回空值，其他结果正常计算。

## 10. 远期优于不套保的概率

远期策略与不套保的人民币金额差额为：

```text
difference(S) = C - H × S
```

因为至少存在一笔正金额远期，所以 `H > 0`。两种方案的盈亏平衡汇率为远期加权平均汇率：

```text
break_even_spot = C / H
```

业务判断：

```text
美元应收或持有美元
→ 策略收入高于不套保时，策略更有利

美元应付
→ 策略成本低于不套保时，策略更有利
```

接口返回：

- 盈亏平衡汇率；
- 远期策略优于不套保的概率；
- 不套保优于远期策略的概率。

在连续概率分布下，恰好等于盈亏平衡汇率的概率视为 0，因此两个概率之和为 100%。

“达到目标的概率”和“优于不套保的概率”是两个不同指标，响应结构和后续前端文案不得混淆。

## 11. 结果范围变化

第一版使用较宽 90% 人民币金额范围的宽度比较结果稳定程度：

```text
range_width = maximum_amount - minimum_amount
```

接口分别返回：

- 不套保 90% 金额范围宽度；
- 远期策略 90% 金额范围宽度；
- 策略宽度减去不套保宽度；
- `reduced`、`unchanged` 或 `increased`。

这里描述的是“预测金额范围变窄或变宽”，不把它包装成完整的金融风险度量。

系统不能假设所有远期策略都会降低风险：

- 全额套保的范围宽度为 0；
- 部分套保通常缩小范围；
- 超额套保仍可能缩小、恢复或扩大范围；
- 具体结果必须按照公式计算。

## 12. 响应结构

响应主要分为：

```text
distribution
├─ 预测中心值
├─ 年化历史波动率
├─ 到期天数
├─ 常见 50% 汇率范围
└─ 较宽 90% 汇率范围

no_hedge
├─ 预计人民币金额
├─ 常见 50% 金额范围
├─ 较宽 90% 金额范围
└─ 目标达标概率（可选）

forward_strategy
├─ 预计人民币金额
├─ 常见 50% 金额范围
├─ 较宽 90% 金额范围
├─ 目标达标概率（可选）
└─ 第七阶段已有的覆盖情况与风险提示

comparison
├─ 盈亏平衡汇率
├─ 远期优于不套保的概率
├─ 不套保优于远期的概率
└─ 90%金额范围变化

data_sources
├─ 机构预测来源
└─ 历史市场数据来源
```

`result_kind` 继续明确结果是人民币收入还是人民币成本。

第一版不返回密集概率点。纯计算层保留“给定到期汇率计算两种方案金额”的清晰边界，后续增加完整概率曲线时可以在其上取更多分位点，而不改变本阶段接口含义。

## 13. 外部数据失败和缓存

沿用现有数据服务规则：

```text
优先使用 24 小时内的每日缓存
          ↓ 无有效缓存
尝试实时抓取
          ↓ 抓取失败
使用允许期限内的后备缓存，并明确标记 stale_fallback
          ↓ 仍不可用
返回明确的数据不可用错误
```

预测和历史数据各自保留现有新鲜度、完整性和有效性检查。

如果外部数据不可用，自动概率接口不使用虚构的默认汇率或波动率。用户仍可使用第七阶段的确定性情景接口进行手工假设分析。

## 14. 风险提示

沿用第七阶段覆盖规则和远期方向：

```text
美元应收或持有美元 → 到期卖出美元
美元应付           → 到期买入美元
```

超额套保继续允许计算，但必须返回：

- 超额美元金额；
- 覆盖率；
- `over_hedged` 状态；
- 额外方向性风险提示；
- 本阶段未计算保证金、授信和额外资金占用的说明。

结果还必须保留市场数据局限性：

- 当前只是单一机构预测试验；
- 到期日预测可能由相邻机构预测点插值得到；
- 波动率来自历史数据，不保证未来波动相同；
- 概率结果是模型估算，不是保证结果；
- 平台不构成交易或套保建议。

## 15. 测试

测试不依赖真实外部网络，使用固定预测和固定历史波动率，至少覆盖：

### 15.1 纯计算

- 一笔和多笔远期；
- 美元应收、持有美元和美元应付；
- 部分、全额和超额套保；
- 不套保与远期策略的预计金额；
- 50%和90%金额范围；
- 超额套保时金额范围上下限正确排序；
- 全额套保时金额范围上下限相同；
- 有目标和无目标；
- 线性斜率为正、为零和为负时的目标概率；
- 远期优于不套保的概率及盈亏平衡汇率；
- 90%金额范围缩小、不变和扩大；
- 所有概率均在 0 到 1 之间；
- 金额最终保留两位小数。

### 15.2 自动协调服务

- 预测与历史波动率被正确传入纯计算器；
- 不套保与远期策略共用同一分布；
- 数据来源原样包含在结果中；
- 上游数据错误不被吞掉或替换成虚构数据。

### 15.3 API

- 成功请求返回约定结构；
- 输入错误返回现有统一友好错误；
- 外部数据不可用返回现有数据错误；
- 现有全部后端测试继续通过。

实现后应在 `/docs` 页面输入一个可手工复算的远期案例，核对预计金额、目标概率、盈亏平衡汇率和范围宽度。

## 16. 完成标准

用户可以输入一笔真实 USD/CNY 敞口、一笔或多笔同日到期的银行远期报价，以及可选目标金额。系统自动读取现有机构预测和历史波动率，在同一概率分布下返回不套保与当前远期策略的：

- 预计人民币金额；
- 常见 50% 和较宽 90% 金额范围；
- 目标达标概率；
- 远期优于不套保的概率；
- 90%金额范围变化；
- 覆盖状态、风险提示和数据来源。

计算使用解析公式，不依赖大量随机模拟。结果能够用固定测试数据复算，并明确说明单一机构预测和历史波动率模型的局限性。后续可以在相同纯计算边界上增加完整概率曲线和多策略比较。
