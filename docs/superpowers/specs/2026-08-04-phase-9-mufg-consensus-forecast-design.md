# 第九阶段：ING 与 MUFG 综合汇率预测设计

> 日期：2026-08-04
> 项目：`fx-hedging-platform`

## 1. 目标

把现有单一 ING 的 USD/CNY 到期汇率预测升级为 ING 与 MUFG 两家大型金融机构的综合预测。

两家机构均正常时，系统分别把每家机构的季度预测换算到用户的具体到期日，再进行 50%/50% 等权平均。只有一家机构可用时，系统允许使用单机构临时备用，但必须明确说明当前不是多机构综合预测。两家都不可用时，不生成虚构结果。

升级后的综合预测继续供以下功能共同使用：

- 不套保自动概率分析；
- 远期策略自动概率分析；
- 独立到期汇率预测查询。

本阶段只增加第二家机构和综合逻辑。完整概率曲线作为第十阶段单独设计。

## 2. 第二家机构选择

第二家机构使用 MUFG Research：

```text
机构：MUFG Bank / Mitsubishi UFJ Financial Group
页面：https://mufgresearch.com/forecasts/
数据：FX Rates 表格中的 USD/CNY 季度预测
访问：公开、无需登录
```

选择 MUFG 的原因：

- 属于大型国际金融集团；
- 官方页面直接公开 USD/CNY 预测；
- 提供未来多个季度的明确数值；
- 页面标注最近一次 FX 预测更新时间；
- 数据位于 HTML 表格中，比依赖 PDF 版面更适合自动提取；
- 与现有 ING 数据结构相近，便于分别插值后透明地综合。

UOB 作为后续备用候选。UOB 当前主要通过 PDF 发布预测，本阶段不同时接入，避免把 HTML 抓取、PDF 解析和多机构综合三个风险叠加在一起。

## 3. 范围

### 3.1 本阶段支持

- 货币对仅支持 `USD/CNY`。
- 自动抓取 ING 和 MUFG 的公开预测。
- 每家机构独立保存原始季度预测、更新时间和抓取时间。
- 每家机构独立匹配用户到期日。
- 两家有效估算使用 50%/50% 等权平均。
- 一家失败或无法覆盖日期时，另一家可以作为单机构备用。
- 两家都失败时返回明确错误。
- 保留 24 小时正常缓存和 7 天网络故障后备缓存。
- 继续检查来源新鲜度、数值有效性和预测期限。
- 独立预测接口和两个自动概率接口都返回可追踪的机构明细。

### 3.2 本阶段不支持

- 三家或以上机构。
- 历史准确率权重、动态权重或用户自定义权重。
- 机构分歧度评分。
- 把预测分歧直接加入波动率。
- PDF 预测解析。
- 预测历史数据库和回测。
- 完整概率曲线或密集概率点。
- 超过未来 365 天的用户到期日。
- 机构观点文本、新闻或宏观报告的自然语言分析。

## 4. 用户流程

用户不需要增加任何输入字段：

```text
用户输入敞口、到期日、目标和策略
                  │
                  ▼
         系统自动读取两个来源
        ┌─────────┴─────────┐
        ▼                   ▼
      ING                 MUFG
        │                   │
        ▼                   ▼
独立匹配用户到期日   独立匹配用户到期日
        │                   │
        └─────────┬─────────┘
                  ▼
         综合或单机构备用
                  ▼
        系统预计到期汇率
                  ▼
          现有概率分析模型
```

前端以后只需要显示新增的机构明细和综合状态，不需要要求用户理解或填写机构权重。

## 5. 为什么先匹配再平均

每家机构可能使用不同的季度点、更新时间和预测范围。因此必须先把每家机构的预测分别换算到用户日期：

```text
ING 原始季度点
      ↓ 独立插值
ING 用户日期估算

MUFG 原始季度点
      ↓ 独立插值
MUFG 用户日期估算

两个用户日期估算
      ↓ 等权平均
系统综合估算
```

示例：

```text
用户到期日：2026-11-15
ING 换算结果：6.68
MUFG 换算结果：6.62

系统综合预测
= 6.68 × 50% + 6.62 × 50%
= 6.65
```

不能直接混合两家机构所有原始季度点后再插值，因为那会隐藏来源差异，也难以说明每家机构对最终结果的贡献。

## 6. MUFG 抓取规则

MUFG 抓取器只访问官方页面：

```text
https://mufgresearch.com/forecasts/
```

解析器需要找到：

- FX Rates 表格；
- 唯一的 `USD/CNY` 行；
- 对应的季度表头；
- 至少两个有效的未来季度预测；
- `Latest FX forecast update` 对应的完整更新日期。

季度表头转换为季度末日期：

```text
Q1 YYYY → YYYY-03-31
Q2 YYYY → YYYY-06-30
Q3 YYYY → YYYY-09-30
Q4 YYYY → YYYY-12-31
```

所有汇率必须为有限且大于 0 的数。季度日期必须唯一并严格递增。页面不得出现两条相互冲突的 USD/CNY 预测行。

以下情况视为 MUFG 来源无效：

- 找不到目标表格或目标行；
- 表头数量与预测值数量不一致；
- 季度标签无法识别；
- 汇率为空、非数字、无穷、非正数；
- 更新时间缺失、无效或位于未来；
- 有效未来预测点少于两个；
- 页面结构产生多个无法唯一确定的候选表格。

解析失败不能返回部分数据，也不能沿用一个已经被确认结构异常的新页面。

## 7. 单机构服务边界

将“单一机构数据读取”和“多机构综合”分成两个层次。

### 7.1 单机构预测服务

每个机构服务负责：

- 调用自己的抓取器；
- 读取和写入自己的缓存；
- 检查来源更新时间；
- 使用共同匹配器换算到用户到期日；
- 在用户日期早于第一个机构预测点时，按现有规则使用 FRED 市场参考值作为前端锚点；
- 返回该机构的换算结果和完整来源信息。

ING 和 MUFG 必须复用共同的匹配器、日期限制和缓存规则，不能各自复制一套插值公式。

### 7.2 综合预测服务

综合服务只负责：

- 并列调用两个单机构服务；
- 收集成功结果和失败原因；
- 决定等权综合或单机构备用；
- 分配权重；
- 生成最终响应和限制说明。

综合服务不解析网页、不直接操作缓存，也不重新实现插值。

## 8. 缓存与新鲜度

ING 和 MUFG 使用完全独立的缓存文件：

```text
python/.cache/market-data/ing-usdcny-forecast.json
python/.cache/market-data/mufg-usdcny-forecast.json
```

每家机构均采用：

```text
24小时内缓存       → daily_cache
无正常缓存且抓取成功 → live_fetch
抓取发生网络错误
  且有7天内旧缓存   → stale_fallback
没有可用后备缓存    → 该机构不可用
```

来源内容本身距离当前日期超过 45 天时，视为来源过旧。网络错误可以使用 7 天内缓存；结构无效、内容无效或未来日期不能被旧缓存悄悄掩盖。

缓存校验必须核对：

- 机构名称；
- 货币对；
- 官方来源 URL；
- 来源更新时间；
- 抓取时间及其时区；
- 季度点唯一、有序、有限且为正数。

## 9. 综合与备用规则

### 9.1 两家都有效

```text
aggregation_status = equal_weight_consensus
source_count = 2
is_consensus_forecast = true
ING weight = 0.5
MUFG weight = 0.5
```

最终汇率：

```text
expected_maturity_spot
= ING matched_spot × 0.5
+ MUFG matched_spot × 0.5
```

综合值使用十进制运算，最终保留最多 6 位小数，避免二进制浮点误差影响可复算性。

### 9.2 只有一家有效

```text
aggregation_status = single_source_fallback
source_count = 1
is_consensus_forecast = false
可用机构 weight = 1.0
```

响应必须同时返回：

- 可用机构名称；
- 不可用机构名称和稳定的原因代码；
- 当前不是综合预测的限制说明；
- 另一机构恢复后会重新使用等权综合的说明。

单机构备用不能继续使用旧的 `single_source_trial` 名称，因为这已经不是产品设计中的长期单机构试验，而是双机构系统的降级状态。

### 9.3 两家都无有效估算

如果两家原始数据均可用，但都无法覆盖用户日期，返回现有预测期限不足错误：

```text
forecast_horizon_insufficient
```

如果两家因为网络、缓存、来源过旧或内容无效而都不能提供估算，返回：

```text
forecast_sources_unavailable
```

如果失败原因混合，例如一家期限不足、另一家网络不可用，同样返回 `forecast_sources_unavailable`。只有所有来源都明确因为日期超出各自预测范围而失败时，才返回 `forecast_horizon_insufficient`。

系统不使用当前即期汇率、固定默认值或随机数字冒充机构预测。

## 10. 接口升级

继续使用现有接口：

```text
GET /api/v1/forecasts/usd-cny/maturity-estimate
```

不新增一个功能重复的“综合预测接口”。原接口从单机构响应升级为多机构可追踪响应。

保留的顶层字段：

- `status`；
- `currency_pair`；
- `quote_convention`；
- `valuation_date`；
- `maturity_date`；
- `expected_maturity_spot`；
- `source_count`；
- `aggregation_status`；
- `is_consensus_forecast`；
- `sources`；
- `limitations`。

每个 `sources` 组成项返回：

- `institution`：`ING` 或 `MUFG`；
- `matched_maturity_spot`：该机构换算到用户日期的结果；
- `weight`：本次综合中的权重；
- `matching`：直接匹配或插值方式、锚点和权重；
- `source_updated_date`；
- `source_url`；
- `forecast_points`；
- `cache_status`；
- `fetched_at_utc`；
- `cache_age_hours`；
- `is_stale`。

另加：

```text
unavailable_sources
```

其中每项包含机构名称和稳定原因代码。两家均正常时该列表为空。

原来只描述 ING 的顶层 `matching` 不再保留；匹配过程移动到各自机构的 `sources[].matching` 中。当前项目没有已发布的外部 API 客户端，本阶段可以在更新所有内部调用和测试后完成这次响应结构升级。

## 11. 下游自动分析

现有自动分析协调服务继续只读取：

```text
forecast.valuation_date
forecast.expected_maturity_spot
```

因此金融概率计算公式不需要修改。变化发生在预测值的来源：

```text
以前：ING 单一预测
现在：ING + MUFG 等权综合，或明确的单机构备用
```

自动分析结果中的 `data_sources.forecast` 使用升级后的完整预测响应，所以不套保和远期策略接口都会自动显示机构贡献、权重、不可用来源和综合状态。

## 12. 限制说明

两家都正常时至少说明：

- 当前仅包含两家机构，不代表完整市场共识；
- 两家机构暂时等权，没有使用历史准确率；
- 插值结果是系统估算，不是机构对该具体日期的直接预测；
- 机构预测可能与实际结果明显不同。

单机构备用时额外说明：

- 当前只有一家机构可用；
- 当前结果不是多机构综合预测；
- 不可用机构及原因已列出。

现有概率接口中的历史波动率、模型估算和非交易建议说明继续保留。

## 13. 错误处理

用户到期日不在未来 365 天内时，在访问任何外部来源之前返回：

```text
forecast_maturity_invalid
```

单一来源失败不能直接终止整个请求。综合服务记录失败后继续检查另一来源。

不可用来源原因使用稳定代码，例如：

```text
fetch_failed
source_invalid
source_stale
horizon_insufficient
```

公开 API 不返回内部堆栈、网页正文或底层网络错误详情。

## 14. 测试

自动测试不访问真实机构网站，使用固定 HTML、固定快照、临时缓存路径和固定时间。

### 14.1 MUFG 解析器

- 正常解析官方结构中的 USD/CNY 行；
- 季度标签转换为正确季度末日期；
- 正确读取完整更新时间；
- 缺少或重复目标行；
- 表头与数值数量不一致；
- 非数字、非正数、无穷和空值；
- 重复或乱序季度；
- 更新时间缺失、无效或位于未来；
- 有效未来预测点不足；
- HTTP、重定向和超时错误转换为现有抓取错误。

### 14.2 通用缓存与单机构服务

- ING 与 MUFG 缓存相互独立；
- 24 小时正常缓存避免重复抓取；
- 网络失败使用 7 天内后备缓存；
- 超过 7 天缓存不可用；
- 未来时间缓存被忽略；
- 结构无效不能被旧缓存掩盖；
- 来源更新时间超过 45 天被拒绝；
- 两家复用同一个日期匹配器和 FRED 前端锚点规则。

### 14.3 综合服务

- 两家直接预测的 50%/50%平均；
- 两家分别插值后再平均；
- 综合值按 6 位小数规则处理；
- ING 失败时 MUFG 单机构备用；
- MUFG 失败时 ING 单机构备用；
- 一家无法覆盖日期时另一家备用；
- 两家都无法覆盖日期时期限不足；
- 两家数据都不可用时返回综合不可用；
- 成功和失败来源的机构名称、权重、状态和限制说明正确。

### 14.4 API 与下游回归

- 预测接口返回两家来源明细；
- 单机构备用响应可追踪；
- 不套保自动概率接口使用综合值；
- 远期策略自动概率接口使用综合值；
- 数据来源在两个自动概率响应中完整保留；
- 现有金额、概率、缓存、输入错误和外部数据错误测试继续通过；
- 全部测试不依赖真实网络。

## 15. 完成标准

用户输入一个未来 365 天以内的到期日后，系统可以从 ING 和 MUFG 的公开页面分别取得并验证 USD/CNY 季度预测，分别换算到用户日期，并在两家有效时返回透明的 50%/50%综合预测。

当一家机构临时不可用或无法覆盖日期时，系统使用另一家机构继续工作，并明确标记 `single_source_fallback`、100%权重、不可用机构和原因。当两家都不可用时，系统返回明确错误，不生成默认预测。

升级后的综合预测被独立预测接口、不套保自动概率分析和远期策略自动概率分析共同使用；所有响应保留机构原始点、匹配过程、权重、缓存状态、更新时间和限制说明，并通过无网络依赖的自动化测试。
